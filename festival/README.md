## 生成AIの使い方（どの場面で、どう使ったか）

- @EnvironmentObject
  @EnvironmentObject は、SwiftUI のプロパティラッパーで、ビュー階層全体で共有されるオブジェクトを、親から子へ自動的に受け渡すためのもの。

- ヘッダーを作り直し　戻るボタン、正解枚数、時間を一行に変更し、標準の戻るボタンを隠し自作の戻るボタンでは反応しませんでした。
\n原因：拡大された写真が、戻るボタンの上に重なって、タップを先に受けていました。
.clipped() を付けていたので、見た目は枠の中に収まっていましたが、見た目を切り取るだけだったのでタップを受ける範囲は切り取れない。
\n解決策：.clipped() や .cornerRadius() は、見た目を切るだけなので、タップを受ける範囲も切りたいときは、.contentShape(...) や .allowsHitTesting(false) を使う。
